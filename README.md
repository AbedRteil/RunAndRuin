# Run & Ruin

A dark fantasy endless runner made with Unity and C#.

You play as a wizard, fight enemies, dodge obstacles, and collect souls while trying to beat your best score. The longer you survive, the faster and more challenging the game becomes.

## Download

[**Download the Windows Build — v1.0.0**](https://github.com/AbedRteil/RunAndRuin/releases/download/v1.0.0/Run.Ruin_Github_version.zip)

Download the ZIP, extract it, and launch the game executable to play.

### Features
- Wizard movement, jumping, and attacks
- Enemy and obstacle spawning
- Increasing game difficulty
- Score and best score tracking
- Souls collection
- Character selection
- Death and restart system

### Controls
Mobile:
- **Swipe up:** Jump
- **Tap:** Attack
Windows:
- **Space:** Jump
- **Left-Click:** Attack

### Built with
- Unity
- C#
- Unity Input System

### Running the project
Clone or download the repository, then open the project folder through Unity Hub. Let Unity finish importing the assets before opening and playing the game.
